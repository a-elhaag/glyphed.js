# Product

## Register

brand

## Users

Frontend developers and design engineers evaluating a small, framework-neutral library for expressive handwritten text on the web.

## Product Purpose

Show the library working immediately, make experimentation effortless, and give developers enough technical detail to install and ship it with confidence.

## Brand Personality

Crafted, playful, technical, minimal, and experimental.

## Anti-references

Avoid generic SaaS landing pages, decorative dashboard cards, fake handwritten fonts, and documentation that hides the working result behind marketing copy.

## Design Principles

- Let the library demonstrate every important claim.
- Keep the path from curiosity to working code short.
- Treat glyphs as crafted objects, not decoration.
- Make technical details precise and easy to scan.

## Accessibility & Inclusion

Target WCAG 2.2 AA with semantic structure, keyboard access, visible focus, sufficient contrast, and a reduced-motion experience.
