strokes.js documentation

Write text that draws itself.

A dependency-free ESM package for animated, hand-drawn SVG text.

Install

Choose the package manager already in your project. No separate publishing step is needed for pnpm, Yarn, or Bun. 

npm install strokes-js
pnpm add strokes-js
yarn add strokes-js
bun add strokes-js

Start here

Use write(). It adds the SVG and draws it when the element becomes visible. This is the right choice for most pages. 

import { write } from "strokes-js";

write("#hello", "Hello, world!");

Two useful options

Change the behavior, not the setup.

01

Show it immediately

Turn animation off for labels, compact UI, or reduced visual motion.

write("#label", "Already here", {
  animate: false,
});

02

Change the ink

Set one CSS property on the container. Every glyph inherits it.

.announcement {
  --hw-color: #c63d24;
}

Choose an API

There are three entry points. Pick one based on who owns the DOM and when the animation should start.

Recommended

write()

Use when the library can update the element for you.

Server or framework

renderText() + attach()

Use when you insert the HTML yourself, then want it to animate on view.

Your own trigger

animateWriting()

Use after renderText() when a click or route change should start the drawing.

Observer options

root, rootMargin, and threshold work like standard IntersectionObserver settings. Set once: false to observe again after the element leaves view.

Frameworks and SSR

React

Render into a ref after mount. Re-render when the text changes.

import { useEffect, useRef } from "react";
import { write } from "strokes-js";

export function Handwriting({ text }) {
  const ref = useRef(null);

  useEffect(() => {
    write(ref.current, text);
  }, [text]);

  return <span ref={ref} />;
}

Server rendering

renderText() is pure string output, so it can run during server rendering. Call attach() after hydration when animation is needed. 

import { renderText } from "strokes-js";

const markup = renderText("Server-rendered ink", { animate: false });

Glyphs

Every supported character is a hand-drawn SVG path. Choose a set to inspect its actual output. Unsupported characters are skipped.

To add a character, create its glyph module and register it in the lookup. All glyphs use the same 24-unit viewBox height.

Request a glyph or report an issue

Icons

renderIcon(name, options?) draws a single named icon the same way words draw in, one hand-drawn stroke at a time. It is unreleased and not yet on npm. See the home-page preview. 

import { renderIcon, attach } from "strokes-js";

el.innerHTML = renderIcon("check", { size: 40 });
attach(el);
